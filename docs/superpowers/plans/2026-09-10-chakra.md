# Chakra Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a working macOS menu-bar app that opens a two-ring radial launcher — eight fixed apps outside, five live recents inside — requiring no system permissions.

**Architecture:** Nine focused Swift files compiled by `swiftc` into a hand-assembled `.app` bundle. Pure logic (`Geometry`, `OuterRing`, `Recents`) is kept free of view state so a separate test binary can link and assert against it; stores take an injected `UserDefaults` so tests never touch real preferences.

**Tech Stack:** Swift 6.3.3, AppKit, CoreServices (Metadata), Carbon (HIToolbox) for the hotkey, ServiceManagement for the login item. No third-party dependencies, no Xcode, no SwiftPM.

**Spec:** `docs/superpowers/specs/2026-09-10-chakra-design.md`

## Global Constraints

- **No system permissions.** No Accessibility, Screen Recording, or Automation prompt may ever appear. Dismissal uses `windowDidResignKey`, not a global event monitor; the hotkey uses Carbon `RegisterEventHotKey`, not `NSEvent.addGlobalMonitorForEvents`.
- **Deployment target `arm64-apple-macos14.0`** despite the macOS 26 SDK, so availability is compiler-enforced.
- Bundle identifier `local.chakra`; executable and display name `Chakra`.
- Fixed geometry: `holeRadius 72`, `innerRadius 100`, `innerIconSize 40`, `outerRadius 175`, `outerIconSize 56`, `discRadius 227`, `ringBoundary 133.5`, `outerSlotCount 8`, `innerSlotCount 5`.
- Slot 0 at twelve o'clock, indices clockwise: `θ(i,n) = π/2 − 2π·i/n`.
- Persistence keys exactly: `outerSlots`, `recents`, `didOnboard`, `hotkeyEnabled`, `colorfulHighlights`, `alwaysCenterOnScreen`. Every read defensive.
- Recents queue capped at 40. Inner ring substitutes the next eligible entry rather than leaving a gap.
- Zero compiler warnings.
